# Dataset Information

## Project Name
DataSense AI – Autonomous Data Analyst

## Dataset Purpose

The datasets used in this project are used to demonstrate
automated data analysis, data cleaning, visualization,
anomaly detection and AI-based insights.

## Supported File Formats

The application supports:

- CSV (.csv)
- Excel (.xls)
- Excel (.xlsx)

## Sample Dataset

The sample dataset contains structured information that can
be analyzed by the DataSense AI application.

Example fields may include:

- District
- Population
- Healthcare Data
- Health Indicators
- Monthly Statistics
- Other numerical and categorical attributes

## Data Processing

The application performs the following operations:

1. Dataset upload
2. Data validation
3. Data inspection
4. Data cleaning
5. Statistical analysis
6. Anomaly detection
7. Data visualization
8. AI-generated explanation

## Privacy

No sensitive personal information should be included in
the sample datasets.

## Usage

Upload a CSV or Excel file through the DataSense AI
frontend to start the analysis.
